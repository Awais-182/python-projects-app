# ⏳ Chronos Manipulation Engine

A visually rich, immersive Streamlit web application designed to convert raw time durations (seconds) into human-understandable time units—from years down to seconds.

---

## ✨ Features
* **Time Breakdown:** Converts input seconds using a standard calendar matrix ($1 \text{ year} = 365 \text{ days}$, $1 \text{ month} = 30 \text{ days}$).
* **Lifespan Context:** Displays progress visualizers to put time intervals into human context.
* **Interactive UI:** Features custom styled metric cards, data distribution charts, and dynamic status indicators.
